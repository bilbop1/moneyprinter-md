# GitHub native discovery

## Verdict

**P0 - the required source and the most important compounding surface.** Every
other high-fit channel resolves back to the repository. GitHub can amplify
useful releases, stars, forks, discussions, field reports, and linked installs,
but it cannot guarantee cold-start traffic or Trending placement.

**Status:** rc.3 is public. The tagged source, release asset and digest, clean
seven-skill remote discovery, metadata, topics, social preview, Discussions,
and private vulnerability reporting were verified on 2026-07-19. Retained
named-host invocation is still experimental.

## Current submission path

There is no GitHub directory submission form. Publish the source repository,
then configure its About description, topics, social preview, release,
community profile, and Discussions from repository settings.

Sources: [GitHub topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics),
[README guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes),
[community profiles](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/about-community-profiles-for-public-repositories),
and [GitHub Trending](https://github.com/trending).

## Prerequisites

- Working owner authentication.
- Public repository at the intended URL.
- Clean clone and remote discovery; record exact end-to-end host invocation
  separately instead of treating package discovery as activation.
- README, license, security, contribution, issue templates, and compatibility
  caveats present.
- GitHub private vulnerability reporting enabled.
- An optional monitored conduct-reporting role address if the community later
  needs one; this is not a launch requirement.
- Inspected 1200×630 social preview.
- Owner approval for the public release.

## Review risks

- A provocative repository name can read as scammy without the receipts-first
  explanation above the fold.
- GitHub activity is not a proxy for customer outcomes.
- Buying stars, swapping engagement, mass-opening promotional issues, or
  automating installs would violate the launch's evidence philosophy.
- A social preview or README that displays fabricated money would undermine the
  core claim.
