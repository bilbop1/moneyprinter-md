# Hermes and Kimi compatibility communities

## Verdict

**P1 — credibility and targeted adoption, not a distinct verified listing
surface.** Hermes already searches Skills.sh. Kimi Code CLI natively scans
Agent Skills directories. A community post becomes useful only after each host
has a retained install-and-invocation test.

**Status:** blocked on the public GitHub URL, Hermes/Kimi host validation, and a
current check that the chosen community channel permits project showcases.
Nothing has been posted.

## Current official paths

### Hermes

Hermes documents Agent Skills compatibility and a Skills Hub that searches
Skills.sh, GitHub, direct URLs, and other registries. The primary distribution
route is therefore the P0 Skills.sh publication, followed by a real Hermes
install test.

Source: [Hermes Skills System and Skills Hub](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills).

### Kimi

Kimi Code CLI documents directory-form `SKILL.md` skills in
`~/.kimi-code/skills/`, `~/.agents/skills/`, `.kimi-code/skills/`, and
`.agents/skills/`. This research pass did not verify a first-party public Kimi
skill directory submission form.

Source: [Kimi Code Agent Skills](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/skills.html).

## Prerequisites

- Successful, retained install and router invocation in current Kimi Code CLI.
- Compatibility matrix updated with the exact version/date and evidence.

Do not use product issues, support tickets, or unrelated pull requests as
promotion.

## Exact install-test prompts

Use after copying/installing the complete skill directories:

> Invoke `moneyprinter`. Ask the short interview one question at a time. Do not
> contact, post, purchase, charge, sign, or publish anything.

Expected first behavior: the skill asks for real assets and constraints, does
not fabricate a business route, and retains an external-action approval gate.

## Listing title

> MoneyPrinter.md: seven receipts-first revenue skills for Hermes and Kimi Code

## Short description

> An open-source Agent Skills pack that routes a short business interview to one
> bounded payable test, then keeps real cash separate from booked revenue,
> pipeline, estimates, simulations, and anecdotes.

## Long description

> I built MoneyPrinter.md because a beginner, roofer, lawyer, creator, and
> experienced operator should not get the same generic AI business plan. The
> router starts from actual assets, authority, time, and risk, recommends one
> small experiment and one fallback, and hands off to six narrower skills for
> research, offer design, a payable test, permissioned acquisition, delivery
> proof, and cashflow review. It never promises income or takes an external
> action without specific approval. The repository includes five transparent
> simulated persona runs; host-specific test results are linked separately when
> completed.
