# Code of Conduct

MoneyPrinter follows the [Contributor Covenant Code of Conduct version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The project has not yet published a dedicated enforcement contact. Until it
does, do not include personal, confidential, or safety-sensitive reports in a
public issue. Maintainers should establish a private reporting route before
enabling public participation at scale.
