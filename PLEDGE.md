# The voluntary 1% pledge

If MoneyPrinter produces attributable profit for you, consider voluntarily
returning 1% of that profit through [Ko-fi](https://ko-fi.com/bilbop). No
tracking and no obligation. It funds source review, compatibility checks, and
new field-tested playbooks.

This is a voluntary social contract. It is not a license condition, purchase
requirement, subscription, success fee, tax calculation, or earnings claim.
The repository remains usable if you contribute nothing, and the project does
not ask you to disclose your revenue, profit, customers, payment records, or
personal information to use it.

The confirmed destination is [ko-fi.com/bilbop](https://ko-fi.com/bilbop).
Contribute only if you want to; there is no verification, follow-up, or access
that depends on payment. See [the funding note](docs/funding.md) for the exact
repository configuration.
