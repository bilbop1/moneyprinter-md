# Funding and the voluntary 1% pledge

If MoneyPrinter produces attributable profit for you, consider voluntarily
returning 1% of that profit through [Ko-fi](https://ko-fi.com/bilbop). No
tracking and no obligation. It funds source review, compatibility checks, and
new field-tested playbooks.

This is a social contract, not a license term, purchase requirement, success
fee, or earnings claim. The repository remains usable without payment. The
project does not ask users to disclose profit, revenue, customers, payment
records, or personal information in order to use the skills.

## Confirmed destination

The owner confirmed the Ko-fi username `bilbop` on 2026-07-19. The public page
loads as “Support bilbop” at
[ko-fi.com/bilbop](https://ko-fi.com/bilbop).

The repository's `.github/FUNDING.yml` uses that username verbatim:

```yaml
ko_fi: bilbop
```

That enables GitHub's native sponsor button without changing the MIT license or
adding a payment requirement. GitHub documents the supported funding-file
format in [Displaying a sponsor button in your
repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).
